# Dashboard Interativo de Análise de Vendas

📌 Sobre o projeto

Este projeto apresenta uma análise de vendas desenvolvida utilizando Python, Pandas e Power BI.

O objetivo foi explorar uma base de dados de vendas, calcular indicadores e transformar os resultados em um dashboard interativo, permitindo analisar o faturamento e a quantidade vendida por diferentes perspectivas.

Este foi meu primeiro dashboard interativo, desenvolvido durante meus estudos em Ciências de Dados.

🛠️ Tecnologias utilizadas

- Python
- Pandas
- Power BI
- CSV

🐍 Etapa de análise com Python e Pandas

A base de vendas foi criada e analisada utilizando Python e Pandas.

Durante a análise foram realizadas etapas como:

- exploração da estrutura dos dados;
- verificação dos tipos de dados;
- análise de valores nulos e duplicados;
- criação do indicador de faturamento;
- análise de faturamento por produto;
- análise de faturamento por vendedor;
- análise de faturamento por cidade;
- análise da quantidade vendida por produto;
- exportação dos dados para um arquivo CSV.

O faturamento foi calculado a partir da quantidade vendida e do valor unitário:

faturamento = quantidade × valor_unitario

📊 Dashboard no Power BI

Após a análise dos dados em Python, os dados foram utilizados para construir um dashboard interativo no Power BI.

O dashboard apresenta:

- 💰 Faturamento total;
- 📦 Faturamento por produto;
- 👤 Faturamento por vendedor;
- 📈 Quantidade vendida por produto;
- 📍 Faturamento por cidade.

Os gráficos possuem interação entre si, permitindo explorar os dados de acordo com os filtros selecionados.

📈 Principais resultados

- Faturamento total: R$ 22.470
- Produto com maior faturamento: Notebook — R$ 14.000
- Vendedor com maior faturamento: Ana — R$ 11.800
- Cidade com maior faturamento: São Paulo — R$ 14.070
